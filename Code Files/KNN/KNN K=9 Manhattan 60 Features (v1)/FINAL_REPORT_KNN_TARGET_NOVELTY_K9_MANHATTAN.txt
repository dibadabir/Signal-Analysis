SUMMARY & INTERPRETATION
================================================================================

The conservative KNN model (K=9, Manhattan, 60 features) achieved a mean
accuracy of 66.01% across 5-fold cross-validation, with ROC-AUC
of 0.720, using target + novelty concatenated preprocessing.

Key findings:
• Sensitivity (recall): 66.79% - captures 67% of PD cases
• Specificity: 64.75% - correctly identifies 65% of controls
• False Negative Rate: 33.21% - misses 33% of actual PD cases
• F1 Score: 0.6385 - balanced precision-recall performance

Data leakage prevention:
• Feature selection (mutual information) is performed independently within
  each CV fold using training data only
• Scaling (StandardScaler) is fit on training data only and applied to
  validation data using training statistics
• This ensures unbiased performance estimates and prevents information
  about validation samples from influencing the model
