SUMMARY & INTERPRETATION
================================================================================

The conservative KNN model (K=9, Manhattan, 80 features) achieved a mean
accuracy of 67.68% across 5-fold cross-validation, with ROC-AUC
of 0.732, using target + novelty concatenated preprocessing.

Key findings:
• Sensitivity (recall): 67.77% - captures 68% of PD cases
• Specificity: 67.53% - correctly identifies 68% of controls
• False Negative Rate: 32.23% - misses 32% of actual PD cases
• F1 Score: 0.6553 - balanced precision-recall performance

Data leakage prevention:
• Feature selection (mutual information) is performed independently within
  each CV fold using training data only
• Scaling (StandardScaler) is fit on training data only and applied to
  validation data using training statistics
• This ensures unbiased performance estimates and prevents information
  about validation samples from influencing the model
