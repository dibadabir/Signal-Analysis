TRAINING PIPELINE (Leakage Prevention)
----------------------------------------------------------------------------------------------------
CRITICAL: Holdout subjects are NEVER used in CV or in fitting the feature selector/scaler.
Feature selection and scaling are performed:
  • INSIDE each CV fold (on training data only) for cross-validation metrics
  • ON ALL non-holdout training data when training the final model

Inside each CV fold:
✓ Mutual Information feature selection → 80 features (on fold training data only)
✓ StandardScaler normalization (fit on fold training data only)
✓ KNN training on selected + scaled features
✓ Validation data transformed using fold-fitted selector/scaler

Final model training (after CV):
✓ Mutual Information feature selection → 80 features (on all non-holdout training data)
✓ StandardScaler normalization (fit on all non-holdout training data)
✓ Final KNN model trained on selected + scaled features
✓ Holdout test data transformed using training-fitted selector/scaler
